How it works

The engine is gore, a pure-Go port of DOOM, compiled to WebAssembly. The worker runs it inside workflow code with wazero, and your browser runs the very same doom.wasm, so both play in lockstep.

  1. You press a key. The browser turns it into a DOOM ticcmd and runs it locally right away.
  2. It becomes an Update. Batches of ticcmds are sent to the game's workflow as Temporal Updates.
  3. The workflow plays it too. The workflow steps its own sandboxed engine and checks that its checksum matches yours.

Crash-proof

Kill the worker mid-fight and start it again. The game picks up exactly where it was.

Rewind

Reset the workflow to an earlier event in the Temporal UI to rewind the game.

Playback

Any history replays through Temporal's WorkflowReplayer and renders it as a GIF.

Multiplayer

Co-op and deathmatch for up to 4 players, who can come and go at any time.

Search

Health, kills and map are search attributes, so you can query running games.

Thin client

Switch a game to thin client and every frame is one Update plus one Query.
